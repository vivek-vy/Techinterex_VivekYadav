# Techinterex_VivekYadav
Description:
This is a user-friendly and interactive web-based Quiz Application developed using HTML, CSS, and JavaScript.

Features Implemented:

"Start Quiz" and "Stop Quiz" buttons to control the quiz flow

Dynamic display of questions and options using JavaScript

Timer functionality with auto-next on timeout

Final score shown after completing the quiz or clicking stop

How to Use:

Click on the Start Quiz button to begin.

Read the question and select one of the answer options.

Click Next to proceed or Stop Quiz to end the quiz early.

The final score will be displayed at the end.
